# Shopbot

В ходе данного проекта должно быть разработано приложение состоящее из
двух структурных частей: магазин и пользовательский интерфэйс к нему
в виде телеграм бота.

## shop

Магазин реализует логику взаимодействия покупателя с продавцом.
Магазин должен предоставлять каталог товаров, корзину покупателя,
возможность сделать заказ на доставку товаров в корзине.

### Абстракции предметной области

1. User(пользователь) - пользователь приложения
2. UserRole - определяет покупателя(customer), продавца(seller), админ(admin)
3. Product(name, фасовка, описание, цена) - товар
4. Basket - корзина покупателя
5. Order - заказ на доставку

### Use cases

Во всех последующих сценария, если не указано иного,
полагается что юзер прошел
аутентификацию, у него пустая корзина

#### Seller

1. Просмотр каталога товаров
2. Добавление товара в каталог
3. Удаление товара из каталога
4. Изменение метаинформации товара
5. Просмотр заказов
6. Отметка заказа как выполненного  

#### Customer

1. Просмотр каталога товаров
2. Добавление товара в корзину
3. Удаление товара из корзины
4. Оформление заказа на товары лежащие в корзине 

#### Admin

1. Выдача пользователю прав продавца
2. Отзыв у пользователя прав продавца
