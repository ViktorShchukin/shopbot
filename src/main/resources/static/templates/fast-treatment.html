Ударная обработка воды.

(Проводится при первом запуске и затем, в течение сезона, 1 раз в неделю)

  1. Альгицид — {{ poolGuideDto.algicide }} мл разлейте по периметру бассейна непосредственно в воду при включенной фильтрации.(При первом запуске используйте двойной дозу альгицида)
  2. С помощью мерной емкости отмеряйте {{ poolGuideDto.chlorineGran }} грамм хлора в гранулах.
  3. Растворите гранулы в ведре с водой и разлейте раствор по периметру бассейна при включенной фильтрации.

Обратите внимание! Альгицид- не может применяться как самостоятельное средство для очистки бассейна. Это вспомогательное средство. Он препятствует размножению водорослей, но не убивает их. Используется для профилактики. И обязательно вместе с хлором.

12 часов ПОСЛЕ УДАРНОЙ ОБРАБОТКИ КУПАТЬСЯ ЗАПРЕЩЕНО.

Через 12 часов после ударной обработки сделайте замер уровня хлора в бассейне при помощи таблеточного тестера. При уровне хлора ниже 1.0 можно купаться без риска для здоровья. Оптимальное значение хлора в воде 0.3 - 0.5.
