Использование коагулянта.

Коагулянт применяют в случае, если после ударной обработки вода приобрела мутно-белый оттенок. Коагулянт бывает в жидком виде или в виде таблеток в картриджах.

{% if poolGuideDto.filterType.name == "SAND" %}

С песочным фильтр-насосом применяйте сухой коагулянт в таблетках:

  1. {{ poolGuideDto.coagulatPill }} шт таблеток сухого коагулянта положите в скиммер.
  2. Фильтр-насос включите в режим фильтрации.
  3. Через 12 часов сделайте обратную промывку песка в фильтре.
  4. Если вода была очень мутная, то промойте песок еще через сутки.
{% else %}

С картриджным фильтр-насосом применяйте жидкий коагулянт.

  1. Добавьте {{ poolGuideDto.coagulatLiquid }} мл жидкого коагулянта непосредственно в воду и отключите фильтрацию.
  2. Отстаивайте воду не менее суток.
  3. После отстаивания, на дне бассейна оседают хлопья, соберите их водным пылесосом.
{% endif %}
